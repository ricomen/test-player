# Контейнеры, MIME, движки воспроизведения

## Поддерживаемые контейнеры (сервер)

| Расширение | MIME (`server/index.js`) |
|---|---|
| `.mp4` | `video/mp4` |
| `.webm` | `video/webm` |
| `.ogg` | `video/ogg` |
| `.ogv` | `video/ogg` |
| `.mov` | `video/quicktime` |
| `.m4v` | `video/x-m4v` |
| `.mkv` | `video/x-matroska` |

Файлы с другими расширениями не попадают ни в `/api/videos`, ни в стрим
`/api/video` (для последнего недопустимый путь = 404).

## Выбор движка на клиенте

Логика в `prefersNativeOrNoHtml5Playback(item)` (`public/app.js`).

```text
              ┌── ext === '.mkv' ───────────────► native <video>
              │
item.mime ──► ├── '' или application/octet-stream ─┐
              │                                    ├──► native <video>
              │                          ext .mkv ─┘
              │
              └── canPlayType(mime) === ''       ──► native <video>
                                                       (Video.js не справится поверх того же тега)
              иначе                               ──► Video.js
```

### Почему `.mkv` отдельно

Большинство браузеров не публикуют `video/x-matroska` через `canPlayType` как
поддерживаемый, но Chrome (на Windows/Linux) фактически декодирует H.264+AAC
из MKV нативно. Video.js поверх HTMLMediaElement даёт ровно то же поведение,
но добавляет лишнюю обёртку и часто ругается на отсутствие `type`. Поэтому
`.mkv` рендерится прямо через `<video>` без Video.js.

### Что вернёт `canPlayType`

- `'probably'` — формат уверенно поддерживается.
- `'maybe'` — возможно, поддерживается (нужен пробный запрос).
- `''` — точно не поддерживается.

В `app.js` `'probably'` и `'maybe'` трактуются как «можно дать MIME в Video.js»,
а `''` — как «нужно делать нативный плеер».

## Стриминг

- `res.sendFile(full)` в `/api/video` — Express подключает `send`, которое
  обрабатывает `Range` запросы из коробки. Это критично для:
  - Перемотки длинных файлов (видеоплеер шлёт `Range: bytes=...`).
  - Корректного буферирования (не качаем 1 ГБ MKV целиком).
- `Content-Type` ставится из таблицы `MIME`. Если расширение неизвестно —
  заголовок не выставляется, и браузер угадывает (что почти всегда плохо;
  но мы сюда не попадём, т.к. `walkVideos` фильтрует по `VIDEO_EXT`).

## Превью кадра

`GET /api/thumbnail` вызывает системный `ffmpeg`
(`-ss 0 -frames:v 1 -q:v 2`). Кэш на диске по SHA1(path|mtime|size).
Без установленного `ffmpeg` → HTTP `503`.

## Что **не** делается

- Транскодирование на лету. Сервер отдаёт байты как есть (кроме JPEG-превью).
- Выбор аудиодорожек / субтитров из MKV.
